# Nestling Baby Tracker

A simple baby tracker for feeds, sleep, diapers, medicine, reminders and daily insights.
Everything is stored on the device. No account, no ads.

## Put it online with GitHub Pages
1. Create a new public repository on github.com.
2. Upload every file in this folder (index.html, manifest.webmanifest, sw.js, icon files, .nojekyll).
3. Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root). Save.
4. After about a minute, open https://YOUR-USERNAME.github.io/YOUR-REPO/

## Install on a phone
- iPhone (Safari): Share > Add to Home Screen.
- Android (Chrome): menu > Install app.

Guidance in the app is general and is not medical advice.
